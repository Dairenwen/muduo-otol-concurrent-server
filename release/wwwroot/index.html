建议测试顺序

  1. 先访问 /，确认首页和公共资源成功返回。
  2. 打开 /docs/ 和 /examples/table.html，验证目录与嵌套路径。
  3. 使用 HEAD、长连接与并发客户端核对响应边界。
  4. 访问不存在的路径，确认 HTTP 404 状态。

ONE REQUEST. FOUR STEPS.

从连接，到看见页面。

每个页面都是一个可观察的请求。先看响应头，再看完整正文，最后检查连接是否按预期保持或关闭。

01连接TCP / Reactor
02解析请求行与正文
03路由文件或处理函数
04响应状态码与字节

YOUR FIRST REQUEST

一个命令，检查整条链路。

curl -i http://127.0.0.1:8080/api/status

预期返回 200 与状态 JSON。然后访问首页，确认 HTML、样式和脚本全部加载成功。接口能响应并不表示静态资源路径一定正确。
