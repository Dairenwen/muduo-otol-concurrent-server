HTTP Lab/docs/index.html
GUIDE / 03

先找到入口，再开始测试。

静态资源根目录必须指向 wwwroot。本页同时提供目录首页测试：访问 /docs/ 与 /docs/index.html 应返回相同内容。

手动启动

编译完成后，在项目目录运行以下命令。测试入口会持续提供网页服务，按 Ctrl+C 结束。

HTTP_TEST_SERVE=1 HTTP_TEST_PORT=8080 ./build/test

默认端口为 8080。若使用容器，需要确保端口可从浏览器访问；也可在容器内通过 curl 检查。

自动检查

ctest --test-dir build --output-on-failure

自动模式使用临时端口，结束后回收测试进程，不会持续占用 8080。

STEP BY STEP

启动正式入口。

  1. 构建。在 Linux 环境中生成 server 和两种库。
  2. 启动。默认使用 8080 端口、3 个工作线程与 30 秒空闲超时。
  3. 访问。打开首页，并在开发者工具中核对资源响应。
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
./release/server --port 8080 --threads 3 --timeout 30

服务器会优先查找可执行文件旁的 wwwroot，其次查找上一级的 wwwroot。当前工作目录不会改变默认资源位置。

换端口，换资源目录。

./release/server --port 9090 --wwwroot /absolute/path/to/wwwroot
./release/server --help

相对的 --wwwroot 参数以当前工作目录为基准。也可设置 SERVER_WWWROOT；命令行参数优先。

容器中启动后，浏览器为什么无法访问？

确认容器端口映射、服务器监听端口和访问地址一致。首先在容器内部运行 curl；内部成功后，再检查宿主机的端口转发。

怎样检查首页和目录首页？
curl -I http://127.0.0.1:8080/
curl -I http://127.0.0.1:8080/docs/

两者都应该返回 200 与 text/html。HEAD 有 Content-Length，但没有响应正文。
