PROJECT / 02

一个轻量的并发服务器实验。

基于 Reactor 与工作线程模型，观察连接建立、请求解析、路由分发和响应发送之间的协作。

连接层

监听器接收连接，由事件循环和工作线程处理可读、可写事件。缓冲区保存尚未消费或尚未发送的数据。

HTTP 层

请求上下文逐段解析请求行、头部和正文；静态目录处理器读取文件，动态路由按方法与路径进行匹配。

本站的用途

这是测试内容，页面没有账号系统或真实业务。界面用于验证资源加载和网络行为，不表示已经完成性能评估。

首页、嵌套目录、表单、错误页面和大文件样例共同组成可重复的测试集合。

BUILT TO UNDERSTAND

不同层次，各有清晰的职责。

连接层处理“什么时候能读写”，HTTP 层处理“这些字节是什么意思”。网页提供足够丰富的内容，帮助你检查两层是否协同工作。

01Acceptor接收新连接
02EventLoop分发读写事件
03HttpContext累计与解析请求
04HttpServer生成与发送响应

本站覆盖什么？

场景观察点
静态页面与公共资源资源目录、MIME、正文长度
嵌套目录与编码路径目录首页、URL 解码、路径校验
不同方法的动态请求GET / POST / PUT / DELETE 分发
大文件与并发连接完整字节、响应边界、客户端数据隔离

演示接口不会创建、更新或删除持久化记录。POST 和 PUT 报告正文长度，DELETE 只返回演示结果。
