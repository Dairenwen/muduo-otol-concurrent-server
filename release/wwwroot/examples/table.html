核对响应

在浏览器开发者工具中打开网络面板，检查样式和脚本均来自 /assets/。刷新页面后不应出现意外的相对路径请求。

BEYOND HTML

公共资源，共享同一条路径。

资源地址用途
样式/assets/style.css所有页面的布局与可访问性样式
脚本/assets/app.js筛选、复制请求、状态检查与请求实验

禁用 JavaScript 后，页面导航、原生表单和折叠内容仍然可用。静态文件不依赖外部字体或 CDN。

测试前，确认三件事。

  1. 页面地址与资源根目录对应，嵌套页面不会请求错误的相对资源。
  2. HTML、CSS、JavaScript 分别返回适当的 MIME 类型。
  3. 真实缺失资源返回 404，不能把错误页面的视觉效果当作状态码检查。
